# Folio Portfolio Builder

Folio is a free, browser-based portfolio builder. Create a responsive portfolio, choose from 40 curated presets and 24 visual design styles, customize content and layout, then export a standalone HTML page.

## Requirements

- Node.js 20 or newer
- npm

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and choose **Build my portfolio**.

## Other commands

```bash
npm run typecheck
npm test
npm run build
npm start
```

Portfolio edits are saved in the browser on the current device. The AI generation option is optional and requires a Gemini API key; the rest of the builder works without one.
